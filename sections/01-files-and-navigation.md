Command	What it does
dir	Lists directory contents briefly
dirname	Strips the filename from a path and returns the folder
dirs (builtin)	Lists the folders saved by pushd
find	Searches for files that match criteria
file	Tells you what type of file something is
ln	Creates a link to a file (ln -s makes a symbolic link)
locate	Finds files from a prebuilt database (sudo updatedb refreshes it)
mkdir	Creates folders
mkfifo	Creates a named pipe
mknod	Creates device or special files
mmv	Moves or renames many files at once
mv	Moves or renames files and folders
pathchk	Checks whether a file name is valid on the system
popd (builtin)	Returns to the previous folder from the stack
pushd (builtin)	Saves the current folder and changes to a new one
pwd	Prints the folder you are in
rename	Renames files using a pattern
rm	Deletes files
rmdir	Deletes empty folders
slocate	Finds files, like locate
touch	Creates an empty file or updates its timestamp
v, vdir	Lists directory contents in long format, like ls -l -b
whereis	Finds a command's binary, source, and man page
which	Shows where a command is stored in your $PATH
ls	Lists files and folders
