# Learning Paths

Not sure where to start? Pick the path that matches your goal, then work through its topics in order. Each topic has a section in the notes and a lab in the `Labs` folder. Do the lab before moving on.

Find each topic in the [table of contents](README.md#table-of-contents) and its lab in the [Labs index](Labs/README.md).

## Path 1: Complete beginner

Start here if you've never used a terminal.

1. Files and navigation
2. Viewing and editing text, including redirection
3. Reading manuals and docs
4. Users and groups
5. Packages
6. Processes and system information
7. Environment variables and PATH
8. Troubleshooting log

**Time:** about 2 to 4 weeks at a few sessions a week.

## Path 2: Help desk and IT support

For work that involves fixing user machines and answering "why isn't it working?"

1. Files and navigation
2. Viewing and editing text
3. Users and groups
4. Packages
5. Processes and system information
6. Networking
7. Logs and monitoring
8. Disks and mounts
9. Backups and recovery
10. Troubleshooting log

**Focus:** reading error messages, checking what's running, and restoring data safely.

## Path 3: System administration

For running and maintaining Linux servers or lab machines.

1. Files and navigation
2. Viewing and editing text
3. Users and groups
4. Permissions and ownership
5. Packages
6. Services and logs
7. Disks and mounts
8. Cron and scheduled tasks
9. SSH keys and configuration
10. Firewall basics
11. Backups and recovery
12. Bash scripting basics

**Focus:** keeping services running, controlling access, and automating repeat jobs.

## Path 4: Defensive security analyst

For monitoring systems and spotting unusual activity. This path is about defence only. Offensive work belongs in a separate practice.

1. Files and navigation
2. Viewing and editing text
3. Processes and system information
4. Networking
5. Logs and monitoring
6. Permissions and ownership
7. Finding interesting files
8. SSH keys and configuration
9. Firewall basics
10. Bash scripting basics
11. Docker basics

**Focus:** reading logs, checking who can access what, and writing small scripts to summarise what you find.

## Path 5: Developer and power user

For people who want a faster, more capable terminal and workflow.

1. Viewing and editing text, including redirection
2. Environment variables and PATH
3. Shell customisation (in environment variables and PATH)
4. Bash scripting basics
5. Git basics
6. Docker basics
7. Reading manuals and docs

**Focus:** automating routine work and keeping projects under version control.

## How to use these paths

- Do the lab for each topic before moving on. Reading without doing is the fastest way to forget.
- If a topic is already familiar, skim its section and do its lab. That's enough to confirm you know it.
- Revisit the Troubleshooting log whenever a command fails. Most real problems are already written up there.
- Once you finish a path, pick another one. Many topics appear in more than one path, so the second one goes faster.
